
# RGT 卒業論文スタイルパッケージ

## 概要

`rgt` パッケージは、龍谷大学の先端理工学部数理・情報科学課程における卒業論文のフォーマットを支援するためのカスタムスタイルパッケージです。

## 対応フォーマット

このリポジトリには以下の2つのバージョンが含まれています：

- **TeX版** (`tex/rgt.sty`): LaTeX/XeLaTeX用のスタイルファイル
- **Typst版** (`typst/rgt.typ`): Typst用のスタイルファイル

## 特徴

- **事前定義された変数**: 大学名、学部、課程、年度、学籍番号、指導教員情報など、文書固有の詳細を簡単に設定可能
- **カスタム環境**: 定義、定理、命題、補題、系、註などの数学的な内容を記述するための環境を提供
- **一貫したフォーマット**: タイトル、概要、内容を自動でフォーマットし、適切なスタイリングを提供
- **目次の作成**: シンプルなコマンドで目次を作成可能

## 特別研究論文の内容と体裁（内規・設計正本）

本リポジトリで扱う特別研究論文は、次の内規に従う。エージェントや執筆補助ツールも、この節を正本として解釈すること。組版テンプレート側にも同趣旨のコメントを置いている。

1. **内容**  
   必ずしもオリジナリティーを求めるものではない。教科書を理解し、独自に工夫してまとめたものでもよい。

2. **概要**  
   概要は **1ページのみ**。論文本体とは独立に、論文全体をまとめたものとする。図表・数式・参考文献一覧を含んでよい。

3. **本文の分量**  
   本文（表紙、目次、文献一覧、付録を除く）が A4 判 **6ページを超える（7ページ目に入っている）**ことを最低条件とする。冗長にしないため、詳細や補助資料は付録へ回す。

4. **共同研究**  
   各自の研究分担および執筆分担を序文で明確にする。各自の執筆分担が、単著の場合に準ずる量であることを最低条件とする。

5. **引用**  
   引用であることを明記する。Web ページなどで公開しても問題のないように配慮する。  
   **Web 引用ではアクセス日が必須**（BibTeX では `note = {Accessed: YYYY-MM-DD}` など。Typst 版の `rgt.csl` / サンプル `document_typst.bib` もこの方針）。

ページ区分の目安（組版との対応）:

| 区分 | 本文ページ数に含めるか | 備考 |
|------|------------------------|------|
| 概要 | 含めない | 独立1ページ |
| 表紙 | 含めない | |
| 目次 | 含めない | |
| 序文・各章などの本文 | 含める | 7ページ目に入ること |
| 文献一覧 | 含めない | |
| 付録 | 含めない | 本文の冗長化回避に使う |

## 提出ファイル名

提出する卒業論文のPDFファイル名は、次の形式とする。

```
学籍番号_氏名.pdf
```

例: `Y260123_龍谷諭吉.pdf`

氏名は名字と名前を続けて記載し、スペースは入れない。

## インストール

### TeX版
1. `tex/rgt.sty` ファイルをプロジェクトフォルダか、TEXMFフォルダに配置
2. LaTeX文書のプリアンブルで `\usepackage{rgt}` を追加

### Typst版
1. `typst/rgt.typ` ファイルをプロジェクトフォルダに配置
2. Typst文書で `#import "rgt.typ": *` を追加
